## Qué es

Marketplace es el ecosistema de apps de la plataforma Jelou. Mantiene el catálogo de apps MCP (Model Context Protocol) y gestiona los flujos OAuth2 con terceros, como Google, Slack, HubSpot, Shopify, Meta Ads, Linear y Pipedream. Además, expone un MCP Gateway que usa el workflow engine para ejecutar tools contra APIs externas reales.

También incluye un agente conversacional (LangGraph + reranking con Cohere) para descubrir apps de forma semántica.

## Repositorios

| Repositorio | Qué contiene | Stack |
| --- | --- | --- |
| [`marketplace-service`](https://github.com/JelouLatam/marketplace-service) | API del catálogo de apps, OAuth2 multi-proveedor, MCP Gateway y agente de descubrimiento | NestJS 11 + Fastify, TypeORM, MySQL 8, Redis, LangGraph |
| [`marketplace-apps`](https://github.com/JelouLatam/marketplace-apps) | Servidores MCP de cada integración (`mcps/<nombre>-workspace`) | Deno, TypeScript, Jelou CLI |

Algunos de los MCP que viven en `marketplace-apps`: Alegra, AgendaPro, Bitrix, Calendly, Contífico, Dátil, ElevenLabs, Facturama, Freshdesk, Google Workspace, HubSpot, Jelou KYC, Jelou Shop, Odoo, Shopify, Siigo, Slack, Stripe, Supabase y WooCommerce.

## Arquitectura

  <ArchifyDiagram svg={marketplaceSvg} title="Arquitectura de Marketplace" />
</Frame>

El usuario instala una app desde Jelou Apps y autoriza con OAuth2. Cuando un workflow necesita una tool, el workflow engine la invoca a través del MCP Gateway de `marketplace-service`. El gateway la ejecuta en el servidor MCP correspondiente, alojado en Deno.

La arquitectura completa está en `marketplace-service/docs/PLATFORM-ARCHITECTURE.md` y el detalle de módulos en `docs/ARCHITECTURE.md`.

## Tecnologías

- **Servicio:** NestJS 11, Fastify, TypeORM, MySQL 8, Redis
- **IA:** LangGraph, Cohere (reranking), `@modelcontextprotocol/sdk`
- **Apps MCP:** Deno, TypeScript, Deno Deploy / Subhosting
- **Herramientas:** Jelou CLI, MCP Inspector, Docker Compose, Testcontainers (E2E)

## Publicar un MCP

<Steps>
  <Step title="Desplegar el servidor">
    Desde `mcps/<nombre>-workspace`, ejecuta `jelou mcp:deploy <nombre>-mcp`. Cada deploy genera un `deployment_id` y una URL nueva: `https://jelou-marketplace-{deployment_id}.deno.dev/mcp`.
  </Step>
  <Step title="Sincronizar la ficha">
    Ejecuta `jelou mcp:config <nombre>-mcp --sync-integrations` para subir `integrations.json` al Marketplace.
  </Step>
</Steps>

## Información importante

<Warning>

  - Para desplegar necesitas `typescript` instalado globalmente; sin él falla la extracción de esquemas de las tools.
