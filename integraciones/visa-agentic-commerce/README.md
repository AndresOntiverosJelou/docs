# Visa Agentic Commerce + Jelou

Origen: correo "VISA Agentic AI + Jelou" (Visa Commercial Solutions LatAm), 28-sep-2026.

## Qué ofrece Visa
- VIC (Visa Intelligent Commerce) y TAP (Trusted Agent Protocol): pagos por agentes de IA, tokenización, identidad del agente.
- Integración vía APIs y MCPs.
- Seguridad: Visa Token Service (VTS), Payment Passkeys, biometría.
- Visa Commercial Agentic Assist (B2BA ProxyPay API): descubrimiento de campos, ejecución de pago, estado de transacción.
- Registro en VDP: https://developer.visa.com/identity/user/register

## Casos de uso propuestos (WhatsApp)
Pagos B2B, gastos corporativos, pagos a proveedores, pagos de servicios.

## Lo que Visa pide validar
1. Modelo de integración: ICC, VIC u otra alternativa.
2. APIs y capacidades prioritarias para una primera integración.
3. Casos de uso para un piloto conjunto.
