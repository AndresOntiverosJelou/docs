Generar enlace de pago

Genera un link de pago (o un código de pago, según el proveedor) para que el usuario complete una compra. Crea la orden en el core de pagos de Jelou y devuelve el link listo para enviar. Úsalo cuando el usuario ya confirmó qué va a pagar y por cuánto. El gateway, la empresa y el canal se resuelven automáticamente del contexto: no los pidas ni los inventes.

Obtener el estado del pedido

Consulta el estado de pago de una orden ya creada. Úsalo para saber si el cliente completó el pago (success), sigue pendiente, falló o fue cancelada. Requiere el id de la orden devuelto al generar el cobro.

Por qué no sirve

  • Un solo proveedor por company. El selector obliga a elegir uno; no puedes tener Wompi y Mercado Pago a la vez.
  • Inputs técnicos. Token del core, ID de la app, entorno: el cliente no los conoce.
  • Inputs que cambian por proveedor. Al elegir Wompi aparecen sus llaves; con otro, otras. Inviable de documentar.

Con el esquema nuevo, cada integración ya tiene sus credenciales desde que se instala (pantalla A), así que este modal sobra.
